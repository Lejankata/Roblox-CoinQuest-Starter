# Contributing to CoinQuest Starter

Thanks for considering a contribution.

1. Open an issue explaining the problem or feature you want to add.
2. Keep changes small, original, and easy to understand for beginner Roblox developers.
3. Test changes in Roblox Studio, ideally on desktop and the mobile emulator.
4. Describe your test results in the pull request.
5. Avoid including proprietary Roblox assets, copied game code, credentials, or external tracking.
6. Do not claim automated tests or live player metrics unless you ran or measured them.

**Suggested first contributions:** clearer setup screenshots, animations, better persistence, and beginner-friendly examples.

By contributing, you agree your changes are available under the MIT License in this repository.
